# Docs Style

Rules for AI agents writing Markdown documentation.

## Structure

- Use title case for headings.
- Put each paragraph and list item on one line; never hard wrap.
- Code blocks and tables may span lines.

## Language

- Use simple, short English.
- Use common words; never invent terms.
- Use one short sentence per paragraph or list item.
- Wrap important keywords in backticks.

## Agent Rule Files

- State each rule directly, with no reason or explanation.
- State the general rule, not one narrow example.
- Keep the document short.

## Other Documentation

- Explain setup steps, behavior and decisions when useful.
- Include examples and rationale needed to use or maintain the project.
